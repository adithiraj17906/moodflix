<h1>🎬 Context-Aware Mood-Based Movie Recommender</h1>

<p>
A smart, context-aware movie recommendation system that provides personalized
suggestions based on user mood, time-based context, and interaction behavior.
The system is designed to solve the cold-start problem while remaining
explainable, privacy-friendly, and easy to use.
</p>

<hr>

<h2>✨ Features</h2>
<ul>
  <li>Mood-based movie recommendations</li>
  <li>Context-aware filtering (time of day & weekday/weekend)</li>
  <li>Interaction-driven refinement using user likes</li>
  <li>Continuous recommendations without page reset</li>
  <li>Dynamic trending movies (not static)</li>
  <li>Explainable recommendations for better transparency</li>
</ul>

<hr>

<h2>⚙️ How It Works</h2>
<ol>
  <li>User selects their current mood</li>
  <li>System recommends movies based on mood and genre</li>
  <li>Recommendations are re-ranked using time-based context</li>
  <li>User likes a movie to receive more similar recommendations</li>
  <li>Trending movies update dynamically based on interactions</li>
</ol>
